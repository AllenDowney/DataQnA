# Data Q&A *Data Q&A* is a series of articles where I answer questions from Reddit's statistics forum using Python code in a Jupyter notebook. The subtitle of the series is *Answering the real questions with Python*. I mean "real" two ways: * The questions are real in the sense that someone is genuinely asking. That's why I adhere to the first rule of the statistics forum, "No homework questions". * Along with an immediate, practical question, many posts contain an underlying challenge, or point of confusion, that poses a more fundamental problem -- something we might consider the "real" question. In my replies, I try to address both -- I provide a practial answer to the immediate question, and then a broader answer to the underlying question. At the beginning of each article, there's a link you can use to run the notebooks on Colab. This material is a work in progress, so suggestions are welcome. The best way to provide feedback is to [click here and create an issue in this GitHub repository](https://github.com/AllenDowney/DataQnA/issues).
