## Running the notebooks

The easiest way is Colab: use the links above, or the link at the top of each article. The notebooks install anything Colab doesn't already have.

To run them on your own computer, clone this repository and install the dependencies with pip:

```bash
git clone https://github.com/AllenDowney/DataQnA.git
cd DataQnA
pip install -r requirements.txt
jupyter lab nb
```

Or create a conda environment, which also has the tools for testing and building the site:

```bash
mamba env create -f environment.yml
conda activate DataQnA
```

The notebooks are in `nb/`, each paired with a Markdown version (via [Jupytext](https://jupytext.readthedocs.io/)). To run them all as tests: `make tests`.
